## 4. What is NOT proven / honest limits

1. **No recall win anywhere in the graph work.** Graph route R@10 **0.23–0.25**
   vs exact (6 file-named queries, `GRAPH-ROUTE.md`); graph+anchor adds **0
   recall** (the 4-bucket anchor route already covers the exact top-5). NB:
   `GRAPH-ROUTE.md` also quotes **0.343** — that figure is the *first* run whose
   mean included a query that fell back to brute (R=1.00 by construction), so it
   is inflated; **0.233/0.250** is the clean number. This is a *rough* map /
   fallback, not an accelerator.
2. **Production is unchanged.** Production has trained anchors
   (`data/memcore/kv_anchors.bin`), so the train-free graph route **never fires**;
   the bucket-union flag is **off by default** and adds nothing anyway. Live
   behaviour = the anchor route exactly as before.
3. **The graft bias (λ), not routing, reorders results.** With bias ON (λ=0.05)
   mean R@5 dropped 0.967→0.367. That is the +λ cluster nudge promoting
   non-top-k entries — **why the bias is default-OFF and separate** from the
   routing knobs. Do not attribute that drop to the bucket union.
4. **Warm path is inert at topk≥3** unless `LZ_ROUTE_BUCKETS` pins the bucket
   count (B1 wall: the default route covers the whole index).
5. **The graft graph is a DAG** (0/2,091 non-self pairs have a reverse edge) — a
   *direct* reciprocal is useless; only the indirect (return-path) magnet works.

## 5. Traps (learned this session — do not re-derive)

- **`make` is not installed.** Build with gcc directly (or `mingw32-make`).
- **Tests write to relative `build/…`** → they MUST run with cwd = repo root.
- **Windows: `SO_REUSEADDR` and `SO_EXCLUSIVEADDRUSE` are mutually exclusive.**
  Setting both makes the exclusive `setsockopt` fail `WSAEINVAL(10022)` and the
  port stays shareable (silent split-brain). Use `SO_EXCLUSIVEADDRUSE` alone on
  Windows; keep `SO_REUSEADDR` only on non-Windows.
- **The live binary can be STALE.** After any source change you must rebuild AND
  redeploy `build/ann_search.exe`, then restart (kill → `python ann_keepalive.py
  --once`). Verify with `curl :8096/health` + a search that exposes the new field.
- **`data/graft/` is gitignored** (derived). Rebuild with
  `python scripts/graft_bias.py --magnet indirect --rho 0.5`. A one-way backup of
  the old tables is at `I:/tmp/graft_backup_oneway`.
- **`LZ_ROUTE_LOG` must be a native Windows path** (`data/…`, not `/tmp`).
- **25 commits are unpushed** to `FS_tools.git` — push before switching machines.
- **The amplifier/bias only fire for queries that name a repo path** (`core/x.h`);
  a query with no file token has `g_qn=0` → inert.

## 6. Env knobs (all default OFF / no-op unless both axes are on)

| var | default | effect |
|---|---|---|
| `ANN_GRAFT` | `0` | master switch for the graft layer |
| `ANN_GRAFT_LAMBDA` | `0.05` | bias strength (the thing that reorders) |
| `ANN_GRAFT_DIR` | `data/graft` | tables dir |
| `ANN_AMP_BOOST` | `0` | tombstone × graft amplifier (needs GRAFT + warm) |
| `ANN_AMP_K` | `2.0` | warm-bucket weight multiplier |
| `ANN_GRAFT_CAND` | index size | candidate cap in the train-free route |
| `ANN_GRAFT_BACKWARD` | `0` | expand candidates via in-edges |
| `ANN_GRAFT_BUCKETS` | `0` | add graph-endorsed buckets to a trained route |
| `ANN_TOMBSTONE_WARM` | `0` | warm/cold route reorder |
| `LZ_ROUTE_BUCKETS` | auto | pin the walked bucket count (needed for warm to pay) |

Magnet `rho` is baked into `nb.tsv` by the script, **not** a server env var.
