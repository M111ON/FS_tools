# H1 watcher — act path proven, gate made visible (2026-10-26)

Card `task-t87ad8462`. The watcher (`ann_route_watch.py`, `\ann-route-watch`,
every 5 min) existed and had two heuristics (H1 = unrouted, H2 = dead stamps),
but its act path had never run and the gate that refuses the stamp sidecar was
silent.

## 1. The bug the first real firing would have hit

`main()` called `_heal_dead_route(h, st, sync_st, sig, readonly)` before
`st`, `sync_st` and `sig` were bound (they were loaded further down, in the H1
branch). So the H2 path — the branch whose whole job is to shout — died with
`NameError`, wrote nothing to `.ann_route_watch.log`, and the scheduler recorded
a failure the log could not explain. Fixed by binding
`sig/st/sync_st` immediately after `/health`, before any branch.

Why it was never seen: live always had `route_dead=0`, so the branch was
unreachable; the card's retest is what found it.

## 2. The gate is now visible

`lz_stamp_prefix_ok()` refuses a positional sidecar whose prefix proof
(`regrow-state.json`'s `n_prev` + `last_sid`) does not match the loaded buffer.
Refusing was silent — the route fell back to the jsonl labels or none.

`/health` now carries:

```
"stamp":{"live":63837,"unplaced":0,"side_rows":63837,"gate":"ok","gate_code":0}
```

| field | meaning |
|---|---|
| `live` | rows carrying a live routing stamp (was `stamps_live`) |
| `unplaced` | rows with no stamp at all (`entries - live`) |
| `side_rows` | rows the sidecar claims to cover (0 when it was refused) |
| `gate` | `ok` / `prefix_mismatch` (1) / `no_state` (2) |

`prefix_mismatch` is the dangerous one: the sidecar belongs to a different
index version, so applying it would label the wrong rows. `no_state` means no
proof exists (file missing) — also refused, but a rebuild is the normal cure.

The watcher reads that block in `_stamp_alerts()`: either condition becomes an
`ALERT` line and a non-zero exit, de-duplicated by a signature in
`.ann_route_watch_state.json` so a 5-minute scheduler does not spam. It does
**not** auto-repair a refused sidecar: a wrong restamp is worse than a loud one,
and the H2 heal already covers the case where the route is actually dead.

## 3. Verification

`tests/test_route_watch.py` (10 checks, in `run_tests.py`) runs the watcher as a
real subprocess against a scratch server:

| check | proves |
|---|---|
| W1 | table removed + restart → `routed=0` while the store signature is unchanged → watcher POSTs regrow, logs `HEALED — routed 0->1`, `/health` agrees |
| W2 | a state file whose `last_sid` is not this index → `/health` `gate:prefix_mismatch`, `side_rows:0` |
| W3 | watcher exits 1 and writes one `ALERT` line |
| W4 | a second pass does not duplicate the alert |
| W5 | state file missing → `gate:no_state` |

Note on W1: the order file is an OUTPUT in `labels=derive` mode
(`lz_route_cached` says so), so deleting it does not unroute. The anchors table
is the thing the route cannot live without — that is what the test removes.
