📦 Chat Log Chunker

โหลด export chat log (รองรับไฟล์ใหญ่ผ่าน Web Worker + pagination) → ตัด/แก้ไข turn → จำลอง chunk → export

1) Import ไฟล์

ลากไฟล์มาวาง หรือแตะเพื่อเลือกไฟล์ (.md, .json, .txt — เลือกได้หลายไฟล์)
ยังไม่มีไฟล์

2) ตัว noise-strip (ใช้กับ preview/export เท่านั้น ไม่แก้ต้นฉบับ)

3) Turn list (แบ่งหน้า — แก้ไข/ลบ/เลือกได้)

อัปโหลดไฟล์ก่อน

4) จำลอง Chunk สำหรับ embedding

5) Export
